# Where the Evidence Assistant gets its answer

1. Inspection runs DINOv3 and the selected category's memory bank.
2. FastAPI saves the score, threshold, review margin, verdict, image/heatmap paths
   and model identity in SQLite under an inspection ID.
3. The dashboard sends that inspection ID and your question to `/api/assistant`.
   It does not supply a replacement score/verdict for the assistant to trust.
4. The backend reads that exact saved record and its recent conversation.
5. Direct measurement questions are answered from that record, without asking
   Qwen to guess or calculate a verdict. They are labelled **Saved measurements**.
6. Questions needing explanations retrieve applicable source passages with
   LangChain/BGE. LangGraph coordinates retrieval, local Qwen paraphrases, quote/ID
   checks and visible fallback. The trusted measurement summary is kept separate.

For “Is this anomalous?” the answer names this image's actual verdict, score,
threshold and review band. “Does 0.09 mean accuracy?” explains that the score is
a feature distance, not a percentage. Unsupported root causes still abstain.

Qwen is a text model in this pipeline. **It does not see or independently inspect
the uploaded image.** The heatmap is generated by the vision detector. Image
measurements are evidence about this run; retrieved policies are explanations,
not independent proof that the image contains a particular named defect.

Document citations verify traceability of quoted passages, not the truth of
every interpretation. A measurement-only answer has no document citation because
its source is the saved inspection record. Reports explain empty conversation
and source sections instead of leaving unexplained blank headings.
